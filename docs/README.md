# Docs

- `architecture.md` — Final approved system architecture.
- `roadmap.md` — Phase-by-phase implementation roadmap. Follow sequentially;
  do not skip phases.
- `research.md` — Business/domain research behind the design decisions.
- `decisions.md` — Log of implementation decisions made where the
  architecture left something open. Read this before assuming how something
  should be built.

Read these before changing the system design.
